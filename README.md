### ✨ Key Features
- **Modern Bento UI**: A beautiful, fluid interface with a customizable accent color and dynamic background support.
- **Wayland Native**: Flawless window rendering and hardware acceleration on modern Linux window managers like `driftwm`.
- **Cross-Platform**: Works perfectly on both Linux and Windows.
- **Smart Mod Management**: Built-in support for installing and managing Fabric, Forge, and NeoForge modpacks seamlessly.

> 🤖 **Fun Fact:** The entire codebase of this launcher was completely written and debugged by **Antigravity** (an autonomous AI coding agent by Google DeepMind) acting as a pair-programmer!

For Arch/CachyOS users, the package will be available in the AUR soon!

Добро пожаловать в **HirokiLauncher** — современный, быстрый и настраиваемый лаунчер для Minecraft, который изначально создавался с упором на идеальную работу в Linux (CachyOS / Wayland) и Windows.

### ✨ Главные фичи
- **Стильный Bento UI**: Красивый адаптивный интерфейс с изменяемым цветом акцента и поддержкой кастомных фонов.
- **Нативный Wayland**: Никакого мыла в шрифтах! Идеальный рендеринг окон и аппаратное ускорение в тайловых менеджерах (например, `driftwm`).
- **Кроссплатформенность**: Одинаково хорошо работает и на Linux, и на Windows.
- **Умное управление модами**: Встроенная установка и менеджмент сборок для Fabric, Forge и NeoForge.

> 🤖 **Интересный факт:** Вся кодовая база и логика этого лаунчера были полностью написаны и отлажены искусственным интеллектом — автономным агентом **Antigravity** от Google DeepMind!

### 📦 Установка
Зайдите во вкладку [Releases](https://github.com/ikittohk14-beep/hirokilauncher/releases), чтобы скачать готовые сборки для Windows (`.exe`) и Linux (`.tar.gz`).
Для пользователей Arch/CachyOS пакет скоро будет доступен в AUR!
